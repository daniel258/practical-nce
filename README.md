# When negative control exposures fail to detect bias

Simulation and figure code for **When negative control exposures fail to detect bias**, by Daniel Nevo and Raanan Raz (American Journal of Epidemiology).

The study examines how the magnitude and source of exposure–negative control exposure (NCE) correlation affect the NCE regression coefficient and the power of the NCE bias-detection test. Confounding bias in the exposure effect estimate is a separate benchmark. A small or statistically nonsignificant NCE coefficient need not imply little or no confounding; observed exposure–NCE correlation alone does not establish NCE validity or detection power.

## Requirements and working directory

The simulations were run in R 4.5.2. Figure reproduction was checked with R 4.5.2 and ggplot2 4.0.1; robust standard errors use the sandwich package (checked with version 3.1.1).

```r
install.packages(c("ggplot2", "sandwich"))
```

Normal-error simulations using classical standard errors need only base R. Plotting needs ggplot2; simulations with `robust_se = TRUE` also need sandwich. Run all commands from the project root, the directory containing `R/`, `scripts/`, and `figures/`. In RStudio, open `practical-nce.Rproj`; after extracting Appendix S4, use `CodeForPublication/` as the working directory.

The exact final-production scripts use macOS Quartz and Arial. Their platform requirements and commands are in [figures/production/README.md](figures/production/README.md). The original plotting scripts use the standard R PDF device.

## Simulation designs

The following descriptions refer to the main simulations without measured confounders. `A` is the exposure, `N` the NCE, `Y` the outcome, `U` the unmeasured confounder, and `V` an additional cause of `A` and `N` with no direct effect on `Y`.

| Paper design | What changes | What is held fixed | Question |
| --- | --- | --- | --- |
| Design 0 (`D0`) | Strengths of `U → A` (`a1`) and `U → N` (`c1`) | No `V`; outcome parameters | How do these two relationships affect confounding bias, the NCE coefficient, and detection power? |
| Design 1 (`D1`) | Correlation generated by `V`, through `a2 = c2` | `a1`, `c1`, and confounding bias | Can increasing exposure–NCE correlation reduce detection power when the added correlation comes from `V`? |
| Design 2A (`D2`) | Share of correlation generated by `V`, denoted `pi_V` in the paper and `f`/`f_target` in the code | Confounding bias and total exposure–NCE correlation | Can the same observed correlation correspond to different NCE coefficients and detection power? |
| Design 2B (`D2_VaryA1Rho`) | The Design 2 share across several `a1` and correlation settings | Bias and total correlation within each setting | How does the Design 2 result vary across parameter combinations? |
| Design 2C (`D2_HighRho`) | The Design 2 share at high correlations, with larger `a2` | Bias and total correlation within each setting | What happens in high-correlation settings? Only feasible parameter combinations are simulated. |

For the main designs, the confounding-bias benchmark is the exposure coefficient from `Y ~ A` minus the true exposure effect `b2`. The standard NCE analysis is `Y ~ A + N`; the additional `V`-adjusted analysis is `Y ~ A + N + V`.

## Recreate figures from saved results

With the GitHub `results/` directory present, the original plotting scripts can be run immediately from the project root:

```r
source("figures/MakeFigure_D0.R")
source("figures/MakeFigure_D1.R")
source("figures/MakeFigure_D2.R")
```

These write `figures/Fig_D0.pdf`, `figures/Fig_D1.pdf`, and `figures/Fig_D2.pdf`. Each script's `run_prefix` identifies the saved run it reads. See the production README to reproduce the final main figures from the included input CSVs without running simulations.

## Run new simulations

1. Open the relevant script in `scripts/` and review its settings. The paper uses 1,000 datasets per parameter setting, 1,000 observations per dataset, seed 314, and a 0.05 significance level. A smaller `n_iters` is useful for checking that the code runs, but does not reproduce the paper's results.
2. Run the script from the project root, for example:

   ```r
   source("scripts/Run_D0_Sims.R")
   ```

3. Note the printed `save_prefix`. The script saves `*_sims.rds` (replicate-level and aggregate results), `*_agg.csv` (summaries), and `*_manifest.rds`/`*_manifest.txt` (settings and session information). Some scenarios also save `*_skipped.csv`.
4. To plot this **new** run, edit `run_prefix` at the top of the matching original plotting script to equal that run's `save_prefix`, without any `_agg.csv` suffix, then run the plotting script.

The plotting scripts do not automatically select the latest run: their defaults deliberately point to the saved paper results. New runs receive a new timestamp, even when the seed and simulation settings are unchanged. Selecting a new run is therefore an explicit step.

### Non-normal errors and robust standard errors

For Figures S15–S21, edit these settings **inside** the relevant main simulation script before running it:

```r
noise_dist <- "t"
df_t <- 3
robust_se <- TRUE
```

Setting these variables in the R console before sourcing the script is insufficient because the script assigns its own settings. The t-distributed residual errors are rescaled to the specified variances; `U` and `V` remain normally distributed. Inference uses HC1 sandwich standard errors. After the run, set the matching `_t_Robust.R` plotting script's `run_prefix` to the new output prefix.

### Measured confounders

Use the matching script in `scripts/withX/`, for example:

```r
source("scripts/withX/Run_D2_Sims_WithX.R")
```

These analyses include two measured confounders, one continuous and one standardized binary variable, which affect `A` and `Y` but not `N`. Both are included in all fitted models. The published measured-confounder analyses use normal errors and classical standard errors. Outputs are saved under `results/withX/`; plot them with the corresponding script under `figures/withX/` after selecting its `run_prefix`.

On a case-sensitive filesystem, first change the `source("R/withX/DGM_WithX.R")` line in the chosen runner to `source("R/withX/DGM_withX.R")`, matching the supplied filename exactly.

## Interpreting the output

- `beta_N_fit2` and `beta_N_fit4` in an aggregate CSV are mean NCE coefficients for the standard and `V`-adjusted models.
- `sd_beta_N_fit2` and `sd_beta_N_fit4` are empirical Monte Carlo SDs across simulated datasets. Coefficient bands show the mean plus or minus one such SD, not confidence intervals.
- `se_N_fit2` and `se_N_fit4` are averages of the estimated standard errors from individual regressions. They are distinct from the empirical SDs.
- `power_N_fit2` and `power_N_fit4` are proportions of datasets with a two-sided NCE-test p-value below 0.05. Tests use each dataset's estimated SE, not the across-dataset empirical SD.
- `bias_A_fit1` is the confounding-bias benchmark for the exposure effect estimate; it is not an NCE performance measure. The `WithX` version uses the exposure model adjusted for the measured confounders.

`NoV` in older comments or output names means Design 0. `D2` without a suffix corresponds to Design 2A, `VaryA1Rho` to Design 2B, `HighRho` to Design 2C, and `WithX` to the measured-confounder extension. The code's `f`/`f_target` corresponds to the paper's `pi_V`, the share of exposure–NCE correlation generated by `V`.
